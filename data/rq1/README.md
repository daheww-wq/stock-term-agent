RQ1 슬랭 사전 점검

목적: 에이전트에 쓸 모델이 사전 없이 주식 슬랭을 얼마나 아는지 확인한다. 결과로 테스트셋에 넣을 표현(아는 표현 / 모르는 표현)을 고르고, RQ2 해석의 출발점으로 쓴다.

파일
- rq1_items.csv: 사전 초안 v0.2의 비표준 40 · 종목 약어 10 · 오타 10 (총 60)
- rq1_candidates.csv: 덜 알려진 표현 후보. 직접 모은 표현을 같은 형식으로 행 추가 (id는 C01부터, 유형은 "후보")

실행 (Cursor 터미널, stock-term-agent 폴더에서)
- python scripts/rq1_slang_check.py --dry-run  ← 문항 확인만
- python scripts/rq1_slang_check.py            ← 모델 호출, results 폴더에 CSV 생성

판정 기준 (결과 CSV의 판정 칸에 입력)

| 판정 | 기준 | 예 |
|---|---|---|
| 정확 | 사전 정답과 핵심 의미가 같다 | 떡상 → "주가가 짧은 시간에 크게 오르는 것" |
| 부분 | 방향은 맞지만 핵심이 빠지거나 뜻이 넓다/좁다 | 존버 → "오래 보유하는 것" (손실 중 버틴다는 핵심 누락) |
| 틀림 | 다른 뜻으로 답했다 | 데크 → "나무 바닥재" |
| 모름 | 모른다고 답했다 | "모름" |

- 그럴듯한_오답 칸: 틀림인데 자신 있게 그럴듯하게 설명했으면 O. RQ2에서 "규칙 사전을 먼저 쓰는 구조가 맞다"는 판단의 근거가 된다
- 오타 문항은 원표현으로 알아듣고 맞게 설명했으면 정확
- 종목 약어는 종목명을 맞혔으면 정확, 업종만 맞혔으면 부분
- 결과는 건수로 집계한다 (예: 비표준 정확 31/40)
