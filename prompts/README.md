- 각 파일은 system 지침이다. 질문·사전 조회 결과 같은 데이터는 코드(src/nodes/)가 user 메시지로 붙인다
- 노드 1(사전 정규화)과 4(용어 조회)는 LLM을 쓰지 않아 지침 파일이 없다. 노드 7·8·9 고정 문구는 src/fixed_messages.py
- 지침을 고치면 개발용(dev_*.csv)으로만 다시 돌려 확인한다. 측정용 문항을 보고 고치지 않는다

지침 안 예시에 쓴 표현 (측정용 문항을 만들 때 피한다)
- 예시를 외워서 맞히는 것과 고친 것을 구분하기 위해서다
- n0: 엘전, 담아볼까, 시가, 종가, 반대매매, 뽀글장(가상의 신조어), "거품처럼 들뜬 장"(예시 5 짐작 뜻), "거래량 없이 조용한 장"
- n2: 강조어 예시(완전, 다, 좀, 엄청)
- n3: "[풀이: 가=나, 가 다=라(추정)]", "[풀이: 가=나 다 라]", "[풀이: 가 나=다라 하는 장(짐작)]" 형식 예시. 범위 밖 예 "○○ 정보 정리해줘", "○○ 어떤 회사야"
- n5: 짐작 답 고정 문장은 P-092에서 없앴다 (짐작은 답에 쓰지 않고 되묻기만 한다). 되묻기 문장은 src/fixed_messages.py의 CLARIFY
- n5: 관련 용어 안내 문장 형식 "'○○'도 궁금하면 물어봐 주세요." (P-022)
- n5: 비유 소재(장보기, 버스, 날씨), 가상 예시 "A회사 주가가 1만 원이고…"
- n5·n6: 체크리스트 문서의 위반 예·허용 예 문장 (골든크로스 매수 신호, SK하이닉스 좋은 종목, 물타기 좋은 전략 등)

답변 말투 (2026.10.07 본인 선택: 친근한 공부 메이트)
- 해요체 평서형으로 통일, "쉽게 말하면,"으로 시작하는 일상 비유 한 문장, 3~5문장
- 쓰지 않는 끝맺음: ~랍니다, ~답니다, ~거든요, ~죠, ~네요, ~습니다. 앞 내용을 반복하는 마무리 문장 금지
- 비유는 사전 뜻과 어긋나지 않고, 사고파는 행동을 좋게·나쁘게 보이게 하지 않는다

일부러 넣지 않은 것
- 노드 2 지침에 짐작 예시로 동물·사물 이름을 넣지 않았다. 측정용·개발용 가상 신조어가 모두 그런 이름이라, 넣으면 외워서 맞히는 것이 된다 (P-056)
- 노드 2·3 지침에 표준 용어 목록을 넣지 않았다. LLM이 붙인 풀이에는 "(추정)"이 붙고, 노드 3은 사전 풀이를 우선한다(P-016). 넣으면 설정 A(정규화 없음)도 어휘가 맞춰져서 사전의 효과(RQ2 ② 조회 적중)를 잴 수 없다. 표준 용어는 노드 1의 [풀이]를 통해서만 들어간다

랭퓨즈 Prompts (P-031)
- 이 폴더의 지침 6개를 랭퓨즈 Prompts에 "stock-term/<파일 이름>"으로 올린다 (scripts/langfuse_setup.py, 측정 실행 --dataset-run). 내용이 바뀐 지침만 새 버전이 된다
- 기준은 이 폴더의 파일이다. 랭퓨즈 화면에서 지침을 고치지 않는다 (고쳐도 에이전트는 이 파일을 읽고, 내용이 달라 버전 연결만 끊긴다)
- 지침을 고친 뒤 설정 스크립트나 측정 실행을 한 번 돌리면 새 버전이 올라가고, 이후 LLM 호출에 그 버전이 연결된다
